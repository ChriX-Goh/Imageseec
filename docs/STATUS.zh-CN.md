# Imageseec 2.0 b2 简报

更新：2026-11-06。当前测试版 **2.0 b2**，Chrome 数字版本 `2.0.0.2`，测试包 `dist/Imageseec-v2.0-b2.zip`。隔离测试环境的实际扩展设置页已显示 b2。

## 发布边界

GitHub 可同步明确标注的测试版。**未经用户对具体构建的最终验收和提交授权，不上传 Google 商店、不提交审核、不发布线上版本。** 自动化或兼容性测试通过均不能代替用户最终验收。

## 已实现

- 双图对照、记忆单/双图选择、逐张/成组步进、单侧锁定、分隔线边界与双击复位。
- 双图同步临时放大和 Alt 拖动；页面全屏仍是默认行为。
- 全览默认上下阅览：每行从左到右，再向下滚动；可切换左右阅览：每列从上到下，再向右滚动。两种模式保持图片比例，可独立隐藏边框和描述，设置自动保存。点图或 Escape 仍可返回查看器。
- 通用图库识别及按需懒扫描：常见延迟来源、响应式图片、动态 DOM、同组 CSS 图片；扫描停止条件、关闭中止及滚动位置恢复。
- 11 种界面语言、手动语言选择、设置修改即保存、顶部工具栏靠近上沿显示。
- 修复透明卡片与祖先背景误选、透明像素占位图误识别、缩略图比例更新后的缓冲重算，以及关闭后页面坐标恢复。

## 已有证据与缺口

- 46 项自动检查通过；测试包内容与当前源码逐文件一致。新增设置覆盖 11 种界面语言。
- 隔离 Chromium 安装版已验证行列顺序、滚动轴、干净模式和设置持久化。真实键盘与脚本触发的滚轮处理分别记录；逐站脚本不能当作逐站真实指针操作。
- 21 个公开站点各有 24/24 项安装版脚本检查通过（504 项）。b2 已通过专用接口重载；新页面上的常驻入口收到 Ctrl＋单击事件后能打开图片，未请求全屏。
- 生成图库从 6 张扩展到 30 张，正常关闭及中止扫描后页面、内层图库位置分别复原为 720px、190px。横向全览仍沿源页面既有方向触发加载。
- 跨站验收仍有缺项：逐站真实输入、动态内容实际新增和最终模式组合覆盖不足；受登录、年龄确认或反自动化限制的页面未绕过门槛。详见私有 QA 记录。
- 图谱在开发时用来核对设置、布局、预取与扫描的依赖，源码改变后运行指纹检查。私人站点记录、图片和缓存不进入图谱、公开源码或商店素材。
