# Imageseec 发布准备

当前源码为 1.5.2，界面支持英语、简体中文、繁体中文（台湾）、日语、韩语、德语、法语、西班牙语、俄语、乌克兰语和波兰语。默认跟随 Chrome 语言，也可在设置中切换；其他语言使用英语。

Chrome 应用商店开发者账号、注册付款、联系邮箱验证和两步验证已完成。商店草稿中已上传 1.5.2 扩展包。

已准备并录入 11 种语言的商店介绍，英文本地资源与全球资源各有一张 1280 × 800、24 位 PNG 桌面版产品截图。两张截图不展示第三方网站界面或品牌。隐私政策位于主仓库的 `PRIVACY.md`，商店链接也已改为该文件的 GitHub 页面。

后台目前选择免费、公开和所有地区。现有数据披露包含网页内容及浏览活动，因为扩展会在用户主动打开图片时于本地读取当前网页图片与相邻图信息；数据不会发送给开发者。最终提交前，账号持有人仍须核对隐私与权限声明并确认其准确性。

相邻图片识别依据通用网页结构、图片链接和响应式图片来源，不针对特定网站。实际效果取决于网页已加载的内容；不会承诺适配所有网站。产品介绍不包含本地调试地址或特定网站名称。

主仓库目前仍为私有，因此 Google 后台暂时无法访问主仓库首页和隐私政策链接。待公开仓库后，重查后台状态；账号持有人再完成披露确认并提交审核。
