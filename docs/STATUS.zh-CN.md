# Imageseec · 项目准备状态

1.5.0 支持 11 种界面语言：英语、简体中文（中国）、繁体中文（台湾）、日语、韩语、德语、法语、西班牙语、俄语、乌克兰语、波兰语。跟随 Chrome 界面语言，不支持的语言回退英语。已采用 MIT，仓库保持私有。

已准备源码、隐私政策和中英文商店文案草稿，尚未上架。其余商店介绍的翻译与最终宣传素材仍需准备。原来的本地安装目录继续可用；更新后重载插件并刷新网页，无需移动或重装。

产品定位面向熟悉 Photoshop、ACDSee 操作习惯的用户，强调桌面式看图体验。相邻图识别采用通用图片链接、响应式图片、列表、网格和重复卡片结构，兼容情况以实际网页为准。产品介绍不包含开发测试地址；开发方法单独放在 CONTRIBUTING.md。
