# Imageseec 2.0 b6 简报

源码版本 **2.0 b6**，Chrome 数字版本 `2.0.0.6`。本轮只同步源码和图谱，不生成 ZIP，不上传或提交 Chrome 网上应用店。

- 阅览使用固定 4:3 图片区，等比完整显示；上下按行、左右按列。缺地址的同级槽位先显示柔和色块。加载、解码和无内容变化的网页刷新不改变格子；前插补偿位置，未预留的中间新增延至重开或主动改变布局时合并。
- 自动缓存维持视口外前后各两整行／列，加载并解码后才算就绪，两端可独立自定义。提前扫描源图库，优先填补缓存内空槽；有并发限制，失败与取消分开处理。
- 提示随内容位于首尾。明确的完整顺序和总量证据才能确认到头；未知总量和超时只暂停。确认到头后停止自动扫描并持续提示；继续推边需在 500ms 内累计 72 CSS px，单个事件最多 24px，同一手势只复查一次。
- 鼠标左键沿阅览轴拖动 6px 后滚动并取消选图，轻点、Enter 和 Space 保留。Esc 和关闭按钮直接回网页；G／阅览按钮／图片内双击负责模式切换。回源取活动图或阅览中央附近，虚拟恢复限时 2.2 秒，用户操作可中止。
- 11 种语言同步；沿用既有权限，无网站专用分支。

已有证据：61 项单元检查通过；80 张安装态处理器回归 29/29 通过。80 张安装态夹具在反向拖拽时几何差异小于 0.001px，前插锚点偏差约 0.16px；六列中段视口外前后各 12 张已解码。慢速未知总量图库在阅览滚动位置为 0 时由 16 张增至 40 张，暂停后提示暂无新增。真实鼠标验证纵横拖拽；嵌套虚拟列表目标卸载后，退出重新挂载目标，偏差约 18px／517px，低于 15% 门槛。有限图库持续显示首尾；处理器确认两次推边不复查、第三次累计 72px 才开始扫描。
