# License decision

The repository owner selected MIT. The exact license is in the root `LICENSE` file and is included in extension ZIPs. The copyright notice is `Copyright (c) 2026 Imageseec contributors`.

MIT is a short permissive license. It allows use, modification, distribution and commercial use, including incorporation into proprietary products, provided the copyright and permission notice is retained in copies or substantial portions. It includes warranty and liability disclaimers. It does not require forks or derivative changes to be made public.

The owner chose to keep one public GitHub repository as the canonical source. Selecting MIT and choosing repository visibility are separate decisions; the extension's store publication does not require a source repository.

The project-level attribution avoids putting a personal email or legal name in the license file; contributors remain responsible for licensing rights to their contributions. Third-party images, fonts or libraries retain their own license obligations.
