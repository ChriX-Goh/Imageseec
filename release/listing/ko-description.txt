이미지를 보되, 브라우저를 벗어나지 마세요.

Photoshop과 ACDSee의 사진 보기 방식에 익숙한 사용자를 위해 임시 확대, 직접 이동, 정밀한 확대/축소, 빠른 이미지 탐색을 제공합니다. Imageseec는 자체 조작 방식으로 데스크톱의 이미지 보기 경험을 웹에 가져옵니다.

웹페이지 이미지를 콘텐츠 영역을 채우는 집중형 뷰어에서 여세요. 이미지를 마우스 오른쪽 버튼으로 클릭하거나 Ctrl + 왼쪽 클릭을 사용하면 됩니다.

인터페이스는 11개 언어를 지원하며 브라우저 언어에 맞출 수 있습니다.

- 마우스 휠, 화살표 키 또는 화면 가장자리 버튼으로 주변 이미지를 탐색합니다.
- Alt + 휠로 확대/축소하고 Shift + 휠로 1%씩 미세 조정합니다.
- 왼쪽 버튼을 누르고 있으면 임시 확대되고, 놓으면 원래대로 돌아옵니다.
- Alt를 누른 채 드래그해 이미지 경계 밖으로도 자유롭게 이동합니다.
- 배율에 마우스를 올리면 세로 확대 눈금자가 나타납니다. 클릭하면 현재 배율, 페이지에 맞춤, 100%를 순환합니다.
- 이미지를 바꾸어도 배율을 고정할 수 있습니다.
- 화면 아래쪽으로 포인터를 옮기면 주변 이미지의 미리보기가 표시됩니다.
- 미리 불러올 이미지 수와 미리보기 수를 각각 설정할 수 있습니다. 변경 사항은 즉시 저장됩니다.

이미지 비율을 유지하며, 페이지에 맞춰 표시할 때 원본보다 크게 확대하지 않습니다. 원할 때 브라우저 전체 화면을 켜 브라우저 UI를 숨길 수 있습니다.

계정이 필요하지 않으며 분석이나 광고 기능, 개발자 운영 서버가 없습니다. 설정은 브라우저에 로컬로 저장됩니다. 이미지 표시와 미리 불러오기는 웹페이지가 지정한 이미지 서버에 요청합니다.

갤러리 탐색은 페이지에 이미 로드된 콘텐츠를 사용합니다. 사이트마다 호환성이 다르며 canvas 이미지, CSS 배경, 여러 페이지에 걸친 갤러리는 찾지 못할 수 있습니다. Chrome 내부 페이지와 Chrome 웹 스토어에서는 확장 프로그램 사용이 제한됩니다.

Imageseec는 독립 프로젝트이며 Photoshop 또는 ACDSee 제조사와 제휴하거나 보증을 받지 않습니다. 해당 앱용 플러그인이 아닙니다. 제품명은 각 소유자에게 속합니다.
