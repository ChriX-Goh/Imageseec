Imageseec — reviewer instructions

The extension does not require an account, subscription, payment or access to private website APIs.

1. Open an ordinary HTTP/HTTPS page containing an image group made from repeated cards, a list or a grid.
2. Right-click an image and choose “Open with Imageseec”, or use Ctrl + left-click. The viewer opens in the page content area; browser fullscreen is optional.
3. Use the wheel or left/right arrow keys to browse images in the detected group. The overview button opens the adaptive thumbnail mosaic; select a thumbnail to return to the viewer.
4. Use the comparison button to show the opened image beside the next image. Drag the divider or double-click it to reset. Lock either pane and navigate to move only the other pane.
5. Use Alt + wheel to zoom, Shift + wheel for one-percentage-point adjustments, or hover the percentage to reveal the vertical zoom ruler.
6. Hold the left mouse button for temporary magnification and release to restore. Hold Alt while pressing the left button to pan freely.
7. Move to the bottom edge for nearby thumbnails. Open settings for comparison step, minimum pane width and overview thumbnail buffer; changes save immediately.
8. Press Esc or click the close button to exit.

Gallery discovery uses common document structures, responsive and lazy image sources, and CSS backgrounds within detected gallery cards. When the overview needs more thumbnails, the extension scans that group in sections and restores page and nested scroll positions after each scan. Compatibility depends on webpage structure; Canvas images, closed shadow roots and cross-page galleries are not generally discoverable.

All executable code is bundled. HTTP/HTTPS host access runs the lightweight Ctrl-click listener on webpages. Gallery scanning and image preloading begin only after the user opens a viewer. Displayed and preloaded images are requested from the image hosts supplied by the webpage. The developer operates no data-collection backend.

The interface supports en, zh_CN, zh_TW, ja, ko, de, fr, es, ru, uk and pl. Unsupported browser languages use English.
